# Cómo activar las descargas de la Biblioteca

Coloca aquí (en `public/docs/`) los PDF reales con **estos nombres exactos** —
el botón "Descargar" de cada tarjeta ya apunta a estos archivos:

- ley-municipal-completa.pdf
- reglamento-de-implementacion.pdf
- plan-estrategico-2024-2028.pdf
- manual-de-procedimientos.pdf
- informe-de-implementacion.pdf
- directorio-de-actores.pdf
- guia-para-emprendedores.pdf
- bases-de-convocatorias.pdf

En cuanto subas un archivo con el nombre correcto, el botón "Descargar" de esa
tarjeta empieza a funcionar automáticamente — no hace falta tocar el código.

Si necesitas agregar, quitar o renombrar documentos, edita la lista en
`lib/documents.ts`.
